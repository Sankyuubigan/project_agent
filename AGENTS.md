# VibeBridge — правила проекта

Перенос Python-проекта `D:\Projects\project_agent` на Rust + Tauri **без WebView2**
(UI — egui через вендоренный `tauri-plugin-egui`). План работ: `tasks/PRP_PatchLoop_Tauri.md`.

## Сборка и запуск — ТОЛЬКО через rust-build-toolkit

- Сборка: `build.bat` (корень). Тесты: `test.bat`. Релиз: `release.bat`.
- Прямой `cargo build` / `npx tauri` / `npm run tauri` — ЗАПРЕЩЁН (правила владельца §2 desktop_rust_tauri_rules).
- Проверка шага 1: после запуска в диспетчере задач НЕ должно быть `msedgewebview2.exe` от этого процесса.

## Структура

- `crates/agent-core` — чистое ядро (парсер/аплаер, сканер, токены, сборщик промпта). БЕЗ tauri/egui.
- `src-tauri` — окно, egui UI, буфер, конфиг, черновик. Связь с ядром — аргументы + enum UiMessage/CoreEvent.
- `doc/` — инструкции методов (живые md-файлы рядом с exe, НЕ вшиты в бинарник).
- Плагины: path-депы в `D:\Projects\cross-app-plugins\` (logs — канонический логгер; egui — вендоренный, патчен: буфер через arboard).

## Код-конвенции владельца

- Файлы ≤ 500 строк, функции 50–80 строк, принцип дверей (mod.rs).
- `unwrap()`/`expect()` вне тестов запрещены; ошибки не глотаются — каждая в лог.
- UTF-8 без BOM; пути приложения — от `current_exe().parent()`, не от cwd.
- Каждый `std::process::Command` — флаг `CREATE_NO_WINDOW` (0x08000000).
- Версия YY.M.P (бампит build.bat автоматически).
- git-операции в этой папке не выполняем.

## Формат правок «Умный Markdown» (v1.1, вердикты спеца + решение владельца)

- `<<<FILE: путь>>>` … `<<<END_FILE: путь>>>` — путь в закрывающем обязателен;
  голый `<<<END_FILE>>>` — fallback с WARN.
- `<<<<<<< SEARCH` / `=======` / `>>>>>>> REPLACE` внутри блока — точечная замена;
  без них — замена файла целиком.
- `<<<DELETE_FILE: путь>>>` — удаление файла ТОЛЬКО этим тегом.
- Пустой блок FILE…END_FILE = создать пустой файл + WARN (удаления по пустоте НЕТ).
- Текст вне блоков игнорируется. Выход за корень проекта (`..`, абсолютные пути) — ошибка.
- Аплаер двухфазный: dry-run в памяти → атомарная запись «всё или ничего»,
  бэкап затронутых файлов + Undo.
